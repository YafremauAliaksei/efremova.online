# 📋 efremova.online — цели и задачи

Обновлено: 2026-09-26

## 🎯 Цель

Сайт-визитка частного психолога: появляется в поисковой выдаче, и человек
находит на нём контакты психолога.

- быстрый и красивый, на трёх языках (ru, pl, en);
- контакты в один клик: почта, Telegram, WhatsApp, Viber;
- страницы и тексты владелец правит сам из админки;
- браузер посетителя не обращается ни к одному чужому домену;
- ни аналитики, ни рекламы, ни личных данных клиентов на основном домене.

Личный кабинет, запись и платежи — позже, на поддомене `cabinet.` и отдельном
сервере в ЕС. Как устроен сайт: [`docs/13-site-architecture.md`](docs/13-site-architecture.md).

## 🚦 Состояние

Фундамент готов: каркас страниц из базы, админка с входом по одноразовой ссылке,
заголовки безопасности и CSP, ловушки с журналом, CI из восьми ворот. CI зелёный,
открытых оповещений Dependabot и находок CodeQL нет.

`main` защищён ruleset: только PR (squash), три обязательные проверки, CodeQL High
блокирует, force-push и удаление запрещены, обходов нет.

Разработка — в облаке: агент доводит задачу до PR в ветке `claude/<тема>`,
владелец одобряет и сливает. Сторож не даёт агенту сливать, одобрять и читать
токены (docs/03, п.10). Агент действует на GitHub от имени владельца — риск
принят до выхода в прод (docs/03, п.10.2; B.6).

## ✅ Задачи

Значки: ⬜ не начато · 🟡 в работе · ✅ сделано · ⛔ ждёт владельца.

Каждая строка — отдельная ветка `claude/<тема>` и отдельный PR. PR открывается
после слияния предыдущего: иначе каждый следующий приходится обновлять от
`main` и прогонять CI заново (ветки без PR проверки не запускают).
