# 📖 05 — Словарь: что все эти слова значат

> Открывайте этот файл каждый раз, когда в переписке встретилось незнакомое слово.
> Термины отсортированы по смыслу, а не по алфавиту — так понятнее.

---

## Где живёт сайт

| Слово | Человеческое объяснение |
|---|---|
| **Хостинг** | Услуга «ваша программа работает на нашем компьютере 24/7» |
| **Сервер** | Компьютер без монитора, который всегда включён и всегда в интернете |
| **VPS** | Кусок большого сервера, отданный вам в полное распоряжение. Своя ОС, свои права |
| **Ubuntu** | Операционная система для серверов. Как Windows, но без окошек — только команды |
| **Docker** | «Коробка» с программой и всем, что ей нужно. Коробка одинаково работает везде: и у вас, и на сервере |
| **Контейнер** | Запущенная коробка Docker |
| **Docker Compose** | Файл-инструкция «подними вот эти пять коробок и соедини их между собой» |
| **Образ (image)** | Шаблон коробки. Из одного образа можно запустить хоть сто контейнеров |
| **Деплой** | Выложить новую версию сайта на боевой сервер |
| **Прод (production)** | Боевой сервер, который видят настоящие клиенты. Здесь ошибаться нельзя |
| **Staging** | Копия боевого сервера для проверок. Здесь ошибаться можно и нужно |

## Как трафик доходит до сайта

| Слово | Человеческое объяснение |
|---|---|
| **DNS** | Телефонная книга интернета: превращает `efremova.online` в адрес сервера `95.217.x.x` |
| **CDN** | Сеть серверов по всему миру, которые держат копии ваших картинок. Клиенту отдаёт ближайший — поэтому быстро |
| **Cloudflare** | Компания, дающая и CDN, и защиту от атак. Стоит «перед» вашим сервером как фильтр |
| **nginx** | Программа-привратник на вашем сервере: принимает запросы и раздаёт их по назначению |
| **Reverse proxy** | Роль привратника: сам ничего не делает, но знает, кому передать запрос |
| **SSL / TLS** | Шифрование между браузером и сайтом. Тот самый замочек в адресной строке |
| **HTTPS** | HTTP + шифрование. Без него сегодня нельзя вообще |
| **Порт** | Номер «двери» на сервере. 443 — дверь для HTTPS, 80 — для HTTP |
| **Firewall** | Правила «в какие двери пускать, а в какие нет» |

## Из чего сделан сайт

| Слово | Человеческое объяснение |
|---|---|
| **Frontend** | Всё, что видно в браузере: кнопки, тексты, картинки |
| **Backend** | Невидимая часть на сервере: считает, проверяет, ходит в базу |
| **Fullstack** | И то, и другое вместе. Next.js — фуллстек-фреймворк |
| **API** | Способ для программ общаться между собой без человека |
| **Фреймворк** | Готовый каркас, чтобы не писать всё с нуля |
| **React** | Библиотека для сборки интерфейса из переиспользуемых кирпичиков |
| **Next.js** | Фреймворк поверх React: добавляет серверную отрисовку, маршруты, оптимизацию |
| **TypeScript** | JavaScript, который заранее проверяет типы данных и не даёт передать текст туда, где ждали число. Ловит ошибки до запуска |
| **Компонент** | Кирпичик интерфейса: кнопка, карточка, форма. Написал раз — используешь везде |

## Как страница попадает на экран

| Слово | Человеческое объяснение |
|---|---|
| **SSR** | Сервер собирает страницу под каждого посетителя прямо сейчас. Свежо, но медленнее |
| **SSG** | Страница собрана заранее, при выкладке. Сервер просто отдаёт готовый файл. Очень быстро |
| **ISR** | Компромисс: собрана заранее, но сама пересобирается раз в N минут |
| **CSR** | Сервер отдаёт пустую страницу, всё рисует браузер. Быстро для приложений, **плохо для SEO** |
| **Гидратация** | Момент, когда к готовому HTML «подключается» JavaScript и кнопки начинают работать |

## База данных

| Слово | Человеческое объяснение |
|---|---|
| **PostgreSQL** | Программа-хранилище. Как очень умный Excel на стероидах, с гарантиями целостности |
| **SQL** | Язык запросов к базе: «дай всех клиентов, записанных на завтра» |
| **ORM / Prisma** | Переводчик: вы пишете обычный код, он превращает его в SQL. Заодно защищает от инъекций |
| **Миграция** | Записанное изменение структуры базы. Хранится в git, можно откатить |
| **Индекс** | Оглавление для базы. Без него поиск идёт по всем строкам подряд |
| **Транзакция** | «Либо все действия целиком, либо ни одного». Спасает деньги от потери при сбое |
| **Redis** | Сверхбыстрое хранилище в оперативной памяти. Для сессий, кодов и очередей. В проекте пока не используется — вернётся с личным кабинетом |

## Безопасность

| Слово | Человеческое объяснение |
|---|---|
| **XSS** | Злоумышленник вставил свой JS на вашу страницу и крадёт данные посетителей |
| **SQL-инъекция** | В поле ввода написали кусок команды для базы и украли таблицу |
| **CSRF** | Чужой сайт заставляет ваш браузер что-то сделать на нашем сайте от вашего имени |
| **SSRF** | Заставили наш сервер сходить по внутреннему адресу и выдать секреты |
| **DDoS** | Миллионы запросов одновременно, чтобы сайт лёг |
| **WAF** | Фильтр, который узнаёт атаки по «почерку» и режет их до сервера |
| **Honeypot** | Ловушка: фальшивая дверь, в которую полезет только взломщик |
| **CSP** | Список правил для браузера: «выполняй скрипты только отсюда». Главная защита от XSS |
| **Nonce** | Одноразовый случайный код. Браузер запустит только скрипты с правильным nonce |
| **Хеш** | Односторонний отпечаток. Из текста получить хеш легко, обратно — невозможно |
| **Шифрование** | Двустороннее: с ключом можно расшифровать, без ключа — мусор |
| **AES-256** | Стандарт шифрования. Тот же, что у банков и военных |
| **Токен** | Электронный пропуск. Пока действует — вы «свой» |
| **JWT** | Формат такого пропуска, внутри подпись, которую нельзя подделать |
| **OAuth 2.0** | «Войти через Google»: Google подтверждает, кто вы, а пароль нам не передаётся |
| **OTP** | Одноразовый код из 6 цифр, живёт 5 минут |
| **2FA / MFA** | Вход по двум факторам: знаю + имею при себе |
| **Пентест** | Наняли специалиста, чтобы он легально попытался взломать — и рассказал, как |
| **SAST / DAST** | Проверка кода на уязвимости: SAST читает код, DAST атакует работающий сайт |

## Право и регуляторы

| Слово | Человеческое объяснение |
|---|---|
| **GDPR** | Европейский закон о персональных данных. Штрафы до 4 % оборота |
| **UODO** | Польский регулятор по защите данных. Ему сообщают об утечке в течение 72 часов |
| **ISO 27001** | Международный стандарт управления информационной безопасностью |
| **HIPAA** | Американский закон о медицинских данных. Нам не обязателен, но его практики — хороший ориентир |
| **DPA** | Договор с подрядчиком (Hetzner, Stripe) о том, как он обращается с данными |
| **DPIA** | Оценка рисков обработки. Для данных о здоровье обязательна |
| **RoPA** | Реестр: какие данные, зачем, сколько храним, кому передаём |

## Процесс разработки

| Слово | Человеческое объяснение |
|---|---|
| **Git** | Машина времени для кода: хранит все версии, можно вернуться в любую точку |
| **Репозиторий** | Хранилище проекта со всей историей |
| **Коммит** | Сохранённая точка «вот здесь всё работало» |
| **Ветка (branch)** | Параллельная реальность для новой функции, чтобы не сломать рабочую версию |
| **Pull Request** | Предложение влить ветку в основную, с проверками перед этим |
| **CI/CD** | Робот, который на каждый коммит сам проверяет код и выкладывает его, если всё хорошо |
| **GitHub Actions** | Конкретный такой робот |
| **Линтер / ESLint** | Строгий редактор: ругается на плохой и опасный код до запуска |
| **Prettier** | Автоформатирование: сам расставляет отступы, чтобы код везде выглядел одинаково |
| **Спринт** | Отрезок работы с понятным результатом в конце |
| **Терминал** | Чёрное окно, куда пишут команды. Не страшно: команды я буду давать готовыми |
| **npm** | Магазин готовых библиотек для JavaScript + программа для их установки |
| **package.json** | Список «какие библиотеки нужны проекту» |
| **.env** | Файл с секретами (пароли, ключи). **Никогда не попадает в git** |

## Метрики скорости

| Слово | Человеческое объяснение |
|---|---|
| **Lighthouse** | Встроенный в Chrome инструмент оценки сайта по 4 шкалам |
| **Core Web Vitals** | Три метрики Google, влияющие на позиции в поиске |
| **LCP** | Через сколько секунд видно главное содержимое |
| **INP** | Насколько быстро сайт реагирует на нажатие |
| **CLS** | Насколько сильно прыгает вёрстка при загрузке |
| **TTFB** | Время до первого байта ответа сервера |
| **Bundle size** | Сколько килобайт JavaScript скачивает браузер. Чем меньше, тем быстрее |
